# kcpp

ZadClassKcpp

Program konsolowy w języku C++ zawierający zestaw wybranych zadań z laboratoriów.  
Każde zadanie zostało umieszczone w osobnej klasie dziedziczącej po klasie bazowej `ZadKcpp`.

Program posiada menu, z którego można wybrać numer zadania i uruchomić odpowiedni przykład.

## Struktura programu

- "main.cc" — menu główne programu
- "include/" — pliki nagłówkowe ".h"
- "src/" — pliki źródłowe ".cc"
- "ZadKcpp" — abstrakcyjna klasa bazowa dla zadań
-  Budowanie i kompilacja projektu przy użyciu CMake
